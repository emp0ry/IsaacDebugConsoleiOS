THE DETAILS

A closer look
A little more control.

Read-only inspection and validated native commands, inside the existing game window.

01

Find the right command.

Live catalog suggestions, touch autocomplete, session history, scrollable output and Run or Return. Catalog names come from your installed game.

The interface follows window resizing and the software keyboard.

02

Inspect before changing.

Read the seed, room, player position, inventory and bridge status. Search collectible, trinket, card, rune and pill catalogs.

Useful information without guessing an internal item number.

03

Experiment deliberately.

Give or remove collectibles, spawn supported entities, use native Glowing Hourglass rewind, or queue a fresh run with restart or rs.

Mutation requires a paused active run and validated native context.

GETTING STARTED

Choose the host
Keep the right library.

Back up application data first. Use the release built for your loading environment.

Full installation guide ↗
  1. Install the DEB.

    Use a compatible rootless package manager and fully restart Isaac afterward.

  2. Open the console.

    Use its native touch controls or backtick. Opening from gameplay pauses the active run.

  1. Create an app-specific folder.

    Configure Isaac as a private app; do not use the framework as a global tweak.

  2. Import and sign.

    Import the released framework, select the folder for Isaac and leave TweakLoader enabled. Force Sign if required.

  1. Choose the correct binary.

    Use the iOS Embedded archive or the released IsaacDebugConsole-PlayCover.dylib for Apple Silicon.

  2. Embed and sign.

    The documented load path is @executable_path/Frameworks/IsaacDebugConsole.dylib. Preserve existing entitlements and sign the full app.

  3. Restart fully.

    Use one loading method and test the console in the supported game build.

Commands can change the run and saved progress. Use the ready platform-specific PlayCover release; do not substitute the iPhone binary. Follow the current README for installation.

A LITTLE MORE CONTEXT

Good to know.

Does closing always resume the game?+

Only if this console paused that same run. A run that was already paused remains paused.

Does restart keep my items?+

No. Restart and rs queue a fresh run and respect native character, seed and Eden-token rules. They are not collectible R Key.

Does this include the desktop REPENTOGON code?+

No. It is inspired by the desktop console experience and REPENTOGON but contains no REPENTOGON code.
